# 📚 Proyecto: Sistema de Biblioteca

## 📌 Descripción

Sistema en consola para gestionar libros y préstamos dentro de una biblioteca.

---

## 🎯 Objetivo

Desarrollar una aplicación modular aplicando Scrum y flujo Git profesional.

---

## 🧩 Funcionalidades

* Agregar libro (título, autor, año)
* Listar libros
* Actualizar libro
* Eliminar libro
* Marcar libro como prestado o disponible

---

## ⚙️ Requisitos Técnicos

* Validar año como número válido
* No permitir prestar libro ya prestado
* Manejo de errores con `try/except`
* Menú interactivo
* Modularización correcta

---

## 📂 Estructura

```
project/
├─ src/
│  ├─ main.py
│  ├─ menu.py
│  ├─ validations.py
│  ├─ services.py
│  └─ models.py
```
